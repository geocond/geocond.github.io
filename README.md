# GeoCond project page

Project page for *GeoCond: A Conditioning-Aware Reliability Adapter for Feed-Forward 3D Reconstruction*
(WACV 2027), served at https://geocond.github.io/.

The page is static HTML; open `index.html` or serve the folder with any web server. The layout follows the
[Nerfies](https://github.com/nerfies/nerfies.github.io) template (CC BY-SA 4.0). Photographs keep their own
licences, listed under "Image credits" at the end of the page.
